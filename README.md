# 水墨萬年曆

中國水墨留白風格的萬年曆，用 HTML、CSS、JavaScript 寫成，不需要安裝任何東西，用瀏覽器打開 `index.html` 就能使用。

## 功能

- **萬年曆**：年、月、日、星期，上一個月／下一個月、上一年／下一年、回到今天，今年第幾天、今年還剩幾天
- **農曆**：點選日期後，在完整日期的下一行顯示農曆、干支、生肖、節氣（1900～2100 年）
- **節日與假日**：國定假日、補假、補班、連假標示，農曆節日、民俗節日、世界性節日
- **個人行事曆**：新增、修改、刪除行程，事件分類、重要標記，生日與紀念日（可用農曆計算），近日提醒，每日備忘，每日心情
- **即時存檔**：資料存在瀏覽器裡，左下角可以匯出、匯入備份
- **城市天氣**：台灣 22 縣市與國外城市，即時天氣、溫度、濕度、降雨機率、七日預報、日出日落、體感溫度、城市比較、時差、收藏城市、天氣警報
- **每日學習**：英文與程式學習卡，每天自動換一則，可以自己新增
- **八卦占卜**：右上角的小八卦，三錢法搖六次，顯示本卦、變卦，以及學業、愛情、財運、家庭
- **水墨動態**：竹葉搖曳、小船隨水波晃動，每個月份有不同的花框

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的倉庫（Repository），例如 `inkcalendar`。
2. 把這個資料夾裡的所有檔案上傳到倉庫（`index.html` 要在最外層）。
3. 到倉庫的 **Settings → Pages**。
4. **Source** 選擇 `Deploy from a branch`，**Branch** 選 `main`、資料夾選 `/ (root)`，按 **Save**。
5. 等一到兩分鐘，頁面上方會出現網址，按 **Visit site** 就能看到萬年曆。

## 城市天氣

- **天氣資料**來自 [Open-Meteo](https://open-meteo.com/)，免費、不需要授權碼，放在 GitHub Pages 上就能直接使用。
- **台灣天氣警報**來自中央氣象署，需要授權碼，有兩種設定方式：

**方法一：使用 PHP（推薦，授權碼不會被別人看到）**

1. 到[中央氣象署開放資料平臺](https://opendata.cwa.gov.tw/)註冊會員，在「API 授權碼」取得授權碼。
2. 把 `php/config.sample.php` 複製一份，改名成 `php/config.php`，填入授權碼。
3. 用 XAMPP：把整個 `inkcalendar` 資料夾放到 `htdocs` 裡，啟動 Apache，打開 `http://localhost/inkcalendar/`。

`config.php` 已經寫在 `.gitignore` 裡，不會被上傳到 GitHub。

**方法二：不使用 PHP（放在 GitHub Pages 時）**

把授權碼填在 `js/config.js` 的 `CWA_API_KEY`。注意：這樣任何人打開網頁原始碼都看得到授權碼。

兩種都沒有設定時，天氣還是可以正常顯示，只是台灣的天氣特報不會出現，其他城市仍會依照天氣數值顯示高溫、低溫、降雨、強風、雷雨提醒。

## 更新到新版本

1. 把新版本的**所有檔案**上傳到 GitHub，覆蓋舊的檔案（不只 `index.html`，`css/`、`js/` 資料夾也要）。
2. 打開 `index.html`，把所有 `?v=` 後面的數字改成新的版本號（例如 `?v=9.1` 改成 `?v=9.2`），瀏覽器才會下載新的檔案。
3. GitHub Pages 更新大約需要 1～2 分鐘。如果還是看到舊的畫面，電腦按 `Ctrl` + `F5`（Mac 按 `Cmd` + `Shift` + `R`）強制重新整理。

更新程式不會清除瀏覽器裡的行程資料。

## 每年更新國定假日

人事行政總處每年會公告隔年的「政府行政機關辦公日曆表」。拿到新的一年之後，打開 `js/holidays.js`，在 `OFFICIAL` 裡照同樣的格式加一年：

```javascript
2028: {
  off: { "2028-01-01": "開國紀念日", ... },   // 放假日
  work: {}                                     // 補班日
}
```

還沒加入官方資料的年份，程式會依照現行規則自動推算，並在畫面上註明。

## 注意事項

- 國定假日依照政府機關的辦公日曆表，民間公司的放假日可能不同。
- 資料只存在目前這個瀏覽器裡，換電腦或清除瀏覽器資料前，請先「匯出備份」。
- 八卦占卜的解釋僅供娛樂參考。
- 天氣資料：Open-Meteo（CC BY 4.0）；天氣警報：中央氣象署（政府資料開放授權條款）。
