# 水墨萬年曆（GitHub 完整版）

中國水墨留白風格的萬年曆，只用 HTML、CSS、JavaScript 寫成。
**不需要任何伺服器或資料庫**，放上 GitHub Pages 就能使用全部功能；也可以直接雙擊 `index.html` 在電腦上打開。

## 功能

- **萬年曆**：年、月、日、星期，上一個月／下一個月、上一年／下一年、回到今天，今年第幾天、今年還剩幾天
- **農曆**：點選日期後，在完整日期的下一行顯示農曆、干支、生肖、節氣（1900～2100 年）
- **節日與假日**：國定假日、補假、補班、連假標示，農曆節日、民俗節日、世界性節日
- **個人行事曆**：新增、修改、刪除行程，事件分類、重要標記，生日與紀念日（可用農曆計算），近日提醒，每日備忘，每日心情
- **即時存檔**：資料存在瀏覽器裡；左下角可以匯出、匯入備份，用來換裝置
- **城市天氣**：台灣 22 縣市、368 個鄉鎮市區與國外城市，即時天氣、溫度、濕度、降雨機率、七日預報、日出日落、體感溫度、城市比較、時差、收藏、天氣提醒
- **每日學習**：英文與程式學習卡，每天自動換一則，可以自己新增
- **八卦占卜**：三錢法搖六次，顯示本卦、變卦，以及學業、愛情、財運、家庭
- **水墨動態**：竹葉搖曳、小船隨水波晃動，每個月份有不同的花框；滑鼠游標是一把正在拉弦的水墨二胡，移動時琴筒會飄出白色的音符（左下角可以關閉）；手機上手指按下也會出現二胡

## 放上 GitHub Pages

1. 在 GitHub 建立一個新的倉庫（Repository），名稱用英文，例如 `ink-calendar`。
2. 把這個資料夾裡的所有檔案上傳到倉庫（`index.html` 要在最外層）。
3. 到倉庫的 **Settings → Pages**。
4. **Source** 選擇 `Deploy from a branch`，**Branch** 選 `main`、資料夾選 `/ (root)`，按 **Save**。
5. 等一到兩分鐘，頁面上方會出現網址，按 **Visit site** 就能看到萬年曆。

## 天氣

- 天氣資料來自 [Open-Meteo](https://open-meteo.com/)，免費、不需要申請，打開就能用。
- 每個城市都會依照天氣數值，顯示高溫、低溫、降雨、強風、雷雨提醒。
- **選用**：在 `js/config.js` 填入中央氣象署的授權碼，台灣縣市還會多顯示氣象署的天氣特報（例如「大雨特報」）。

## 更新到新版本

1. 把新版本的**所有檔案**上傳到 GitHub，覆蓋舊的檔案（`css/`、`js/`、`images/` 資料夾也要）。
2. 打開 `index.html`，把所有 `?v=` 後面的數字改成新的版本號，瀏覽器才會下載新的檔案。
3. 如果還是看到舊的畫面，電腦按 `Ctrl` + `F5`（Mac 按 `Cmd` + `Shift` + `R`）強制重新整理。

更新程式不會清除瀏覽器裡的行程資料。

## 每年更新國定假日

人事行政總處每年會公告隔年的「政府行政機關辦公日曆表」。打開 `js/holidays.js`，在 `OFFICIAL` 裡照同樣的格式加一年：

```javascript
2028: {
  off: { "2028-01-01": "開國紀念日", ... },   // 放假日
  work: {}                                     // 補班日
}
```

還沒加入官方資料的年份，程式會依照現行放假規則自動推算，並在畫面上註明。

## 注意事項

- 資料存在目前這個瀏覽器裡。換電腦、換手機，或清除瀏覽器資料前，請先「匯出備份」。
- 國定假日依照政府機關的辦公日曆表，民間公司的放假日可能不同。
- 八卦占卜的解釋僅供娛樂參考。
- 天氣資料：Open-Meteo（CC BY 4.0）；天氣特報：中央氣象署；鄉鎮市區座標：依內政部國土測繪中心行政區界計算（政府資料開放授權條款）。
